# Noise Sense — Pune Pulse

A prototype for reporting and exploring urban noise in Pune, built with React, TypeScript, Supabase, Mapbox and chart components.

## What is in the code

- Browser noise-reporting and recording components.
- Map and dashboard views.
- Report and administration interfaces.
- AI-chat interface experiments.

These are implementation areas, not a claim of government adoption, calibrated acoustic measurement, or independently measured prediction quality.

## Local development

```bash
npm ci --ignore-scripts
npm run dev
```

Read `package.json` and `.env.example` first. Map and database-backed features require your own development configuration. A browser microphone reading should not be treated as a calibrated sound-level meter.

## Project status

Learning and product prototype. Deployment configuration exists in the repository, but this README does not certify a current live deployment. Earlier performance and accessibility claims are omitted because a fresh measurement is not recorded here.
